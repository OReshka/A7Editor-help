## Поиск по файлу

[[kbd: Ctrl+F | Открыть поиск]]
[[kbd: F3 | Следующее совпадение]]
[[kbd: Shift+F3 | Предыдущее совпадение]]
[[kbd: Esc | Закрыть поиск]]

Строка поиска появляется над редактором; совпадения подсвечиваются
сразу при вводе.

[[image: images/editor-search.png | Строка поиска с подсветкой совпадений]]

## Поиск файла или команды

`Ctrl+K` открывает палитру команд — она ищет и по командам редактора,
и по именам файлов конфигурации.

## Сворачивание кода

Стрелки на полях редактора сворачивают блоки: тело класса, метод,
многострочный комментарий. Состояние свёрнутых блоков запоминается
для каждого файла.

> [!TIP]
> Сверните всё, кроме метода, над которым работаете, — навигация по
> большому типу станет заметно проще.
