Сессия (workflow) — ваше личное рабочее пространство поверх конфигурации.
Здесь живёт всё локальное: пути к пакетам на диске, открытые файлы,
раскладка панелей, выбранные push-серверы.

[[image: images/workflows-launcher.png | Окно «Сессии»: недавние и закреплённые рабочие пространства]]

## Зачем нужна сессия

Шаблон конфигурации (`configuration.yaml`) — общий для команды и при
работе **не меняется**. Все ваши решения — какие версии пакетов взять,
где они лежат на диске — сохраняются в сессии. Поэтому можно смело
экспериментировать: исходный шаблон останется нетронутым.

## Окно «Сессии»

«Файл → Недавние сессии…» (или автоматически при запуске):

- **Список недавних** — клик открывает сессию со всеми её настройками.
- **Закрепление** — иконка булавки держит важные сессии сверху.
- **Поиск** — по имени, конфигурации или ветке.
- **«Новая сессия»** — начать с чистого листа для той же конфигурации.
- **«Открыть с диска…»** — выбрать папку с `configuration.yaml`.

> [!NOTE]
> Удаление сессии не трогает конфигурацию на диске — удаляются только
> локальные настройки рабочего пространства.

## Где хранится

Сессии лежат в служебной папке приложения (`~/.local/share/A7Editor/workflows/`)
и в git не попадают.
