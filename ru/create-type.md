Тип — один `.js`-файл с DBO-классом: схема данных и код вместе.

[[steps]]
1. Правый клик по пакету в дереве → «Add Type».
2. Введите имя типа — создастся файл и сразу откроется во вкладке.
3. Опишите поля и методы (пример ниже) и сохраните: `Ctrl+S`.
[[/steps]]

## Анатомия типа

```javascript
packet Streams;

@uid '{6e29d8f7-6ef8-484e-9a3b-4f279c6e6b7e}'
@version 5
class A7FileStream {
    @uid '{0a154169-8ebe-4f74-928d-6cbdb35618dd}'
    streamId: int64;

    @uid '{6044a449-5261-430e-89d0-5b5438dbd31e}'
    @flags (memonly, pulse, syncClientToServer)
    pulseInStream: bytearray;

    @uid '{6f839155-545c-429c-ad9c-9fdb36b529b4}'
    getData(depth, idmessage) {
        return streamDataInterval(idmessage, depth, false);
    }
}
```

- `packet Имя;` — принадлежность пакету (совпадает с папкой).
- `@uid` — стабильный идентификатор класса, поля или метода. По нему
  сервер опознаёт элемент после переименований. **Не редактируйте руками.**
- `@version` — версия класса; редактор поднимает её при изменении схемы.
- `@flags (…)` — флаги синхронизации поля (`memonly`, `pulse`,
  `syncClientToServer` и другие).
- Поля — `имя: тип;` (`int64`, `datetime`, `bytearray`, имена других классов).
- Методы — JavaScript с доступом к серверным функциям.

> [!TIP]
> Новые uid редактор расставляет сам — просто опишите поля и сохраните.
> Проверить корректность типа: кнопка «Проверить» в тулбаре.
