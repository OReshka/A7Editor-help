Задачи фиксируют проблемы и замечания, найденные при проверке релиза, —
с привязкой к конкретной версии.

[[image: images/release-issues.png | Панель задач релиза]]

## Завести задачу

[[steps]]
1. Откройте релиз в «Реестре релизов» — панель задач в деталях релиза.
2. Нажмите создание задачи: заголовок, описание, при необходимости —
   пакет и флаг серьёзности.
3. Задача появится в списке с привязкой к версии релиза.
[[/steps]]

## Работа с задачами

- Фильтр: открытые / закрытые / все.
- Комментарии — обсуждение прямо в задаче.
- Закрытие/переоткрытие — по клику на статус.

Задачи хранятся в общем трекере (GitHub Issues репозитория
конфигурации, веха = версия релиза) — команда видит их и без редактора.

> [!NOTE]
> Для создания и изменения задач нужен настроенный git-токен с правами
> на репозиторий конфигурации — см. «Настроить git». Чтение работает
> и без токена.
