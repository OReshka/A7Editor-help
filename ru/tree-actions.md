Дерево проекта — главный пульт структурных операций. Всё — через
правый клик.

[[image: images/tree-context-menu.png | Контекстное меню типа в дереве]]

## Операции с типом

- **Open File** — открыть во вкладке (то же — двойной клик).
- **Rename Type** — переименовать; имя обновится в файле и манифесте.
- **Delete Type** — удалить файл и запись из `configuration.yaml`.
- **Open in System** — показать файл в системном файловом менеджере.
- **Open DBO** — открыть парный `.dbo`-артефакт.

## Операции с пакетом

- **Add Type** — новый тип в пакете.
- **Rename / Delete Packet** — переименовать или удалить пакет целиком.
- **Push packet** — отправить пакет на сервер.

## Отмена структурных действий

«Правка → Отменить» (`Ctrl+Z`) откатывает последнее структурное действие:
создание, переименование, удаление пакета или типа. В меню видно, что
именно будет отменено — например, «Отменить Delete Type».

> [!NOTE]
> «Файл → Обновить» перечитывает конфигурацию с диска — пригодится, если
> файлы изменили вне редактора (например, git pull в терминале).
