Первый шаг при любой проблеме — панель логов («Вид → Панель логов»):
там команда, сервер, код ответа и текст ошибки.

## Сервер

**Красный комбобокс «Серверы не настроены»** — профилей ещё нет.
Кликните по нему и создайте профиль: см. «Подключение к серверу».

**Push падает с 401/403** — сервер отверг токен. Проверьте Bearer-токен
в «Настройки → Профили серверов…».

**«Проверить подключение» — сбой** — проверьте URL (схема/хост/порт)
и сеть. Самоподписанный сертификат на dev? Включите «Разрешить
небезопасный TLS (dev)». Помните: ответ 4xx — это «сервер доступен».

**Админ-панель не подключается** — после смены URL профиля сделайте
«Вид → Админ-панели → Отключиться от сервера» и откройте панель заново.
Для `http`-серверов админка ходит по `ws`, для `https` — по `wss`.

## Git

**Push отвергнут (rejected)** — удалённый репозиторий ушёл вперёд:
«Затянуть» (pull) в окне «Управление версиями…», затем повторите.

**Ошибка доступа (auth failed)** — проверьте ключ/токен во вкладке
«Гит» настроек и нажмите «Протестировать» с URL репозитория.

## Конфигурация

**Тип есть на диске, но не виден в дереве** — он не записан
в `configuration.yaml`. Дерево показывает только манифест.

**Файлы изменили вне редактора** (git pull в терминале и т.п.) —
«Файл → Обновить» (`Ctrl+R`) перечитает конфигурацию с диска.

**Случайно удалили/переименовали** — «Правка → Отменить» (`Ctrl+Z`)
откатывает структурные действия.

## Справка

**Пустая справка** («Справка загружается») — нет сети или контент ещё
не скачан. Нажмите «Обновить справку» в шапке окна.

> [!NOTE]
> Не нашли свой случай? Посмотрите «Частые вопросы (FAQ)» — там
> короткие ответы на типовые вопросы.
