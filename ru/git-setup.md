Git-операции редактора (статусы, коммит, push, pull, теги) используют
общие настройки — задайте их один раз.

[[image: images/settings-git.png | Вкладка «Гит» в настройках]]

Откройте «Настройки → Настройки… → Гит»:

## 1. Удостоверение

«Имя» и «Email» подставляются в авторство коммитов — то же, что
`git config user.name / user.email`. Используйте адрес, привязанный
к вашему git-хостингу.

## 2. Аутентификация

Выберите способ доступа к удалённым репозиториям:

- **SSH-ключ** — путь к приватному ключу (например, `~/.ssh/id_ed25519`).
  Нет ключа? Создайте: `ssh-keygen -t ed25519`, затем добавьте `.pub`-ключ
  на хостинге в раздел SSH-ключей. Passphrase можно не хранить —
  включите «Использовать ssh-agent».
- **HTTPS-токен** — персональный токен доступа. GitHub:
  Settings → Developer settings → Personal access tokens; GitLab:
  Preferences → Access Tokens. Права — чтение/запись репозитория.

## 3. Проверка

В блоке «Проверка» укажите URL любого вашего репозитория и нажмите
«Протестировать» — редактор проверит доступ с текущими настройками.
Пустой URL — проверится только запуск git.

> [!NOTE]
> Поле «Путь к git» оставьте пустым, если git установлен обычным
> способом — возьмётся из PATH.
