Окно статуса Push открывается при отправке пакета и показывает матрицу
«тип × сервер»: что уже ушло, что в работе, где ошибка.

[[image: Матрица push: типы по строкам, серверы по колонкам]]

## Состояния

- **В очереди** — тип ждёт своей очереди.
- **Идёт** — пушится прямо сейчас.
- **Готово** — сервер принял.
- **Ошибка** — сервер отверг; цепочка этого сервера остановлена.
- **Пропущен** — вы нажали «Skip».
- **Отменён** — сессия прервана.

## Действия при ошибке

- **Повторить** — перезапустить упавший тип (например, после правки).
- **Пропустить** — продолжить цепочку без него.
- **Отменить** — остановить всю сессию push.

Текст ошибки сервера разворачивается прямо в окне; полная диагностика —
в панели логов.

> [!NOTE]
> Серверы независимы: ошибка на одном не останавливает отправку
> на остальные.
