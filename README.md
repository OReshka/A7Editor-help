# A7Editor-help

Контент встроенной справки редактора **A7Editor** — источник правды.

Приложение читает справку из «корня контента»: сначала из папки данных
пользователя (`~/.local/share/A7Editor/help`), и только если её нет — из
встроенной в бинарник минимальной копии (qrc). Этот репозиторий — то, что
со временем будет подтягиваться в папку данных (доставка по сети — следующий
этап; UI к ней уже готов).

## Структура

```
manifest.json     # дерево разделов и статей
ru/*.md           # тела статей на русском (Markdown)
images/           # скриншоты (добавляются по мере наполнения)
```

Задел под локализацию: будущие переводы кладутся в `en/`, `de/` и т.д. рядом
с `ru/`. Имена файлов совпадают между локалями.

## manifest.json

```json
{
  "schemaVersion": 1,
  "sections": [
    {
      "id": "getting-started",
      "title": "Как начать",
      "icon": "book",
      "articles": [
        { "id": "welcome", "title": "Добро пожаловать", "file": "welcome.md",
          "summary": "…", "cards": ["quickstart"], "seeAlso": ["download"] }
      ]
    }
  ]
}
```

Поля статьи:

- `id` — глобально уникальный идентификатор (используется в ссылках,
  `cards`, `seeAlso`, навигации «назад/вперёд»).
- `file` — путь относительно `<locale>/` (без `..` и ведущего `/`).
- `format` — `"article"` (по умолчанию), `"faq"` или `"hub"`
  (главная-хаб: hero + карточки разделов).
- `summary` — короткое описание для карточек-ссылок.
- `cards` — список `id` статей, отрисовываемых карточками (маркер `[[cards]]`
  в теле статьи задаёт их место).
- `seeAlso` — список `id` для блока «См. также».
- `qa` — для `format: "faq"`: массив `{ "q", "a" }` (вопрос/ответ).
- `personas` — кому адресована статья: список из
  `"developer"` / `"tester"` / `"devops"` (чипы под заголовком).

Жёстко завязанные id (на них ссылается меню «Справка» редактора —
не переименовывать): `quickstart`, `download`, `release-overview`, `faq`.

`prev`/`next` вычисляются автоматически по порядку обхода дерева — в manifest
их хранить не нужно.

## Разметка статей (Markdown + расширения)

Тела статей — обычный Markdown. Дополнительно распознаются:

- **Коллауты** (GitHub-admonitions):

  ```
  > [!NOTE] Необязательный заголовок
  > Текст примечания (синий).

  > [!WARNING]
  > Предупреждение (жёлтый).

  > [!TIP]
  > Совет (зелёный).
  ```

- **Карточки** — строка `[[cards]]` разворачивается в грид карточек из поля
  `cards` статьи.
- **Картинка** — `[[image: images/file.png | подпись]]`; без пути
  (`[[image: подпись]]`) рисуется плейсхолдер. Клик по картинке открывает
  её во весь экран.
- **Шаги** — нумерованный список внутри маркеров превращается в
  карточки-шаги:

  ```
  [[steps]]
  1. Первый шаг.
  2. Второй шаг (можно
     многострочно).
  [[/steps]]
  ```

- **Горячая клавиша** — строка `[[kbd: Ctrl+S | Сохранить файл]]`
  отрисовывается чипом клавиши с описанием; подряд идущие строки
  группируются в таблицу.
- **Код** — стандартные ``` ```-блоки (отрисовываются моноширинно, с кнопкой
  «Копировать»).

## Правила

- Контент пишется на русском; релиз-заметки и тексты — на русском.
- Не ломать `id` существующих статей (на них завязаны ссылки и навигация).
- `schemaVersion` повышать при несовместимых изменениях формата.
- **При любом изменении статей или картинок бампать `contentVersion`
  в `manifest.json`** — редактор перекачивает контент только когда
  manifest изменился (sha-сравнение); правка одних .md без бампа
  до пользователей не доедет.
